# Wikantik documentation

This is the index to the Wikantik documentation. It is for readers, administrators and developers, and each section below lists the guides written for that audience. Every guide opens with a paragraph saying who it is for and what it covers.

The documentation is split by audience: `docs/user` for people who read and write pages, `docs/admin` for people who deploy and run a wiki, and `docs/developer` for people who change the code. Historical material lives in `docs/archive`.

Reference material that is generated or lives elsewhere:

- [ConfigurationReference.md](ConfigurationReference.md) lists every `wikantik.*` property with its default and type. It is generated by `bin/config-reference.sh --write`; do not edit it by hand.
- [adr/](adr/README.md) holds the architecture decision records.
- [superpowers/specs/](superpowers/specs/) holds the design specs for individual features.
- [wikantik-pages/](wikantik-pages/) is the version-controlled wiki content, including the design pages [HybridRetrieval](wikantik-pages/HybridRetrieval.md) and [PageGraphVsKnowledgeGraph](wikantik-pages/PageGraphVsKnowledgeGraph.md).
