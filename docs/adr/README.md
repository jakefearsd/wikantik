# Architecture Decision Records

This directory holds Wikantik's current ADR series — `NNNN-slug.md` with a
four-digit number (`0001`–`0010` so far). Each record captures a load-bearing
design decision (context, decision, consequences) for the RAG-as-a-Service,
Knowledge Graph, ontology, cluster-taxonomy, and data-access-primitive lines
of work. Indexed from [README.md](../../README.md) and cross-linked from the
design docs that motivated them.

There is a second, older ADR series at [`docs/adrs/`](../adrs/) (note the
plural directory name) — a single record, `001-extract-manager-interfaces-to-api.md`,
using a three-digit numbering convention that predates this directory. It was
never renumbered into this series; both directories are load-bearing and
neither supersedes the other. If you're looking for a decision and it isn't
here, check there.
