# Programming Languages Hub

The language catalog: one page per language, each covering its origin, the design ideas it introduced, and its honest 2026 status. For the historical through-line — six technical regimes from manual memory to AI-native coding — see [Programming Language Evolution](ProgrammingLanguageEvolution); for the theory that distinguishes them, [Type Systems Comparison](TypeSystemsComparison) and [Functional Programming Foundations](FunctionalProgrammingFoundations).

## Systems languages

- [C](CLanguage) — the pointer-memory lingua franca beneath every OS
- [C++](CppLanguage) — multi-paradigm performance: AI engines, HPC, games
- [Rust](RustLanguage) — ownership and borrowing: memory safety at zero cost
- [Zig](ZigLanguage) — comptime and explicit memory; the C-replacement bid
- [Assembly](AssemblyLanguage) — the ISA surface: x86, ARM, RISC-V
- [Ada](AdaLanguage) — high-integrity and formally verifiable via SPARK

## Managed / JVM and .NET

- [Java](JavaLanguage) — enterprise standard-bearer; ZGC-era JVM performance
- [C#](CsharpLanguage) — .NET, Unity, and Native AOT
- [Scala](ScalaLanguage) — OO-functional fusion on the JVM; Spark's language
- [Go](GoLanguage) — CSP concurrency; the cloud-native default
- [Swift](SwiftLanguage) — Apple's safe systems language, Swift 6 concurrency
- [Objective-C](ObjectiveCLanguage) — the message-passing predecessor, in legacy service

## Web and scripting

- [JavaScript](JavaScriptLanguage) — the engine of the web
- [TypeScript](TypeScriptLanguage) — static types over JS; the professional default
- [Python](PythonLanguage) — AI/data lingua franca; the GIL-removal era
- [Ruby](RubyLanguage) — developer happiness; YJIT + Rails 8
- [PHP](PhpLanguage) — 77% of the web; FrankenPHP-era performance
- [Perl](PerlLanguage) — the text-processing era's duct tape
- [SQL](SqlLanguage) — the relational constant since 1974

## Functional, logic, and research lineages

- [Lisp](Lisp) — homoiconicity and GC, since 1958 (see also [LISP in foundations](LispProgrammingLanguage))
- [Prolog](Prolog) — logic programming; neuro-symbolic revival
- [Smalltalk](Smalltalk) — pure OOP and the live IDE
- [Bend](BendLanguage) — interaction-net parallelism on GPUs
- [Mojo](MojoLanguage) — Python syntax at CUDA speed for AI infrastructure

## Historical foundations

- [Fortran](Fortran) — first high-level language; still the HPC yardstick
- [COBOL](COBOL) — the business-logic bedrock under global banking
- [Algol](Algol) — block structure and BNF; ancestor of the C family
- [Pascal](Pascal) — structured programming's teaching language

## Choosing among them

Paradigm and ecosystem beat syntax: memory-safety requirements point to Rust/managed runtimes; AI/data work follows the Python ecosystem; cloud infrastructure defaults to Go; enterprise longevity favors Java/C#; and interop constraints (JVM, .NET, C ABI) usually decide more than language merit. The theory behind these trade-offs: [Type Systems Comparison](TypeSystemsComparison), [Compiler Design Basics](CompilerDesignBasics), and [Concurrency and Synchronization](ConcurrencyAndSynchronization).
